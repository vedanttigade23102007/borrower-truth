## Judgement (Claude, 2 Oct 2026)

**No sign that the red team saw the rules.** The only hits are the data value `deferment_program`, which `fictitious_deferment` writes as a disclosure kind (it's in the table guide). None of the names of the checks added after round 1 appears. The numbers are ordinary code literals.

**Read by a person:**
- All 7 bundled `bookio.py` files are byte-identical to ours, and all 7 `common.py` copies are identical to each other.
- No script imports `os`, `sys`, `subprocess`, `socket`, `urllib` or `shutil`, or calls `open`, `exec` or `eval`. The only `import os` hits are inside our own `bookio.py`.
- **Declared levers:**
  - servicer records: `fictitious_deferment`
  - company history: `shell_roundtrip`
  - the accomplice exception: `seasoned_phantoms`, which pays each customer a "refund" from the operating account first, as the rule requires
- `phantom_collateral` deliberately leaves its invented loans unpaid, because the rule forbids invented payers.

There was no overview README this time. Each attack's README lists the weak points the red team expects a good check to find.
